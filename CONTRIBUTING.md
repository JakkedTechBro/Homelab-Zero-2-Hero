# Contributing

Thanks for wanting to help! Here's where things go:

| You want to… | Go here |
|---|---|
| Ask a question | [Discussions → Q&A](https://github.com/JakkedTechBro/Homelab-Zero-2-Hero/discussions/categories/q-a) |
| Show off your lab | [Discussions → Show and tell](https://github.com/JakkedTechBro/Homelab-Zero-2-Hero/discussions/categories/show-and-tell) |
| Request an episode | [Discussions → Ideas](https://github.com/JakkedTechBro/Homelab-Zero-2-Hero/discussions/categories/ideas) |
| Report a mistake in a guide | [Open an issue](https://github.com/JakkedTechBro/Homelab-Zero-2-Hero/issues/new/choose) |
| Fix a typo yourself | Click ✏️ **Edit** on any guide page and open a pull request |

> [!WARNING]
> This repo is public. Never paste passwords, API keys, tokens, `.env` contents or your public IP in issues, discussions or pull requests.

Be cool, no gatekeeping. Everyone started at zero.
