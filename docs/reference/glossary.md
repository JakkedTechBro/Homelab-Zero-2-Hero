# Glossary

Every term from the series, in plain English. Grows with each episode.

## Git and documentation (Ep00)

| Term | Plain English |
|---|---|
| **Git** | A save button with a time machine. Every save (commit) is kept, so you can always go back. |
| **GitHub** | A website that stores your Git saves online, so every device can sync and others can see your work. |
| **Repository (repo)** | A project folder that Git is tracking. |
| **Commit** | One save point, with a short message describing what changed. |
| **Push** | Upload your commits to GitHub. |
| **Pull** | Download the latest commits from GitHub. |
| **Clone** | Make a full copy of a GitHub repo on your computer. |
| **Branch** | A separate line of work. Ours is `main`. |
| **`.gitignore`** | A list of files Git should never save, like passwords and `.env` files. |
| **`.env` file** | A file holding secrets (passwords, keys) that your configs read from. It never goes in Git. |
| **Markdown** | Plain text with simple symbols for formatting: `#` for headings, `**bold**`, `-` for lists. |
| **Obsidian** | A free notes app that saves everything as Markdown files in a normal folder (called a vault). |
| **PowerShell** | Windows' modern command-line shell. Different from the older Command Prompt. |
