# Homelab Zero 2 Hero

![Homelab Zero 2 Hero by Jakked Tech Bro](assets/banner.svg)

**Build a homelab from nothing, episode by episode.** Free software, affordable gear, and every step explained so you can copy it.

## How to use these guides

Every episode guide has the same shape, so you always know where to look:

1. **Prerequisites:** what you need before you start
2. **What you'll learn:** the concepts, in plain English
3. **Steps:** commands you can copy, with a note on what each one does
4. **Common mistakes:** what trips people up, and how to fix it
5. **Check it worked:** a quick test so you know you nailed it

> [!TIP]
> Anything in `<angle-brackets>` is a placeholder. Replace the whole thing, brackets included, with your own value.
